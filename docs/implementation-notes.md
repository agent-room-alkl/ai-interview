# 实现与验证说明（2026-10-15）

## 已实现
- 顶部中英文界面切换并通过 Cookie 保存，面试语言独立选择；报告与导出 HTML 跟随面试语言。服务条款、隐私长文及部分第三方登录界面仍保留原文。
- 新增 `/interview/pitch`：30/60 秒计时录音、回听、手动修正转写、提交反馈、参照示范重练。使用现有登录和练习权限，无需上传简历。快速练习不进入面试历史。
- 普通语音回答默认手动提交，可选择停顿后自动提交；提交前可清空重说。达标后手动选择下一题，刷新后仍保留本题及得分。
- 修改识别文字会替换原回答，避免重复增加历史记录。
- PCM 累积足够音频后调度、正确处理奇数字节与末尾短块；首块播放时同步更新说话状态；取消旧播放不会覆盖新播放状态。
- 清空回答时屏蔽迟到的旧识别结果；语音连接超时或断开会显示错误；岗位保存网络失败时可重试，分析失败后可手动选语言和岗位。
- 过期后创建新会话、重新进入旧面试、聊天及语音接口均检查权限；历史报告仍可查看。
- 免费试用从首次创建练习／提交快速练习起连续 24 小时，可无限创建 10/20/30 分钟练习。试用首次领取与创建会话在同一事务内，通过用户行锁防止并发重复领取。
- 仅销售 $3/7 天、$9/30 天；移除新的 day 包购买和 $19 档。旧 day 包仍可履约，历史订单按原始天数退款。
- 购买时在已有付费或免费剩余时间后叠加；付费履约和退款锁定用户记录，避免并发覆盖有效期。

## 验证
- `npm test`：9 项测试，覆盖套餐、首次试用、到期边界、付费优先、叠加与退款、PCM 分包、重说时迟到识别结果、麦克风清理。
- `node scripts/smoke-scoring-rubric.mjs`：10 项检查；修正原脚本仍断言 80 分、而实际通过线为 75 分的不一致。
- `npx tsc --noEmit`、`npm run lint`、`npx next build`。

## 上线前
- 必须先执行 `npx prisma migrate deploy`，增加 `User.trialEndsAt`。未连接生产数据库，也未部署或推送。历史已消耗试用不重置，历史付费权限不回写。
- 本地没有数据库、Clerk、OpenAI、Stripe 密钥；真实登录、支付/退款 Webhook、浏览器麦克风和开场语音仍需配置测试环境后联调。代码层修复不等同于已验证真实网络下完全无卡顿。
- `next build` 有既存 unpdf/import.meta 打包警告。
- `npm audit` 报告 16 项依赖告警（1 critical、12 high、3 moderate），见同目录 JSON。包括现有 Next.js 依赖，需单独评估升级与兼容性；未自动执行破坏性大版本升级。


## 电梯演讲个性化模板补充
- 移除顶部电梯演讲小链接，保留高对比度语言切换，以及创建面试和练习中心的醒目入口。
- 电梯演讲页由服务端读取当前登录用户的已保存简历，客户端可检查、修改或清空；这些编辑不会覆盖保存的简历。
- 反馈综合本次演讲和去除联系方式后的背景，提供推荐演讲模板、分段时间安排、个性化依据及待确认信息；评分只依据实际表达，不能用简历中未说出的内容补分。
- 没有简历时明确标注仅依据本次表达，缺少事实用占位提示，不虚构经历。新一轮录音时保留参考模板。
- 修复空白或只有联系方式的简历被标准化为非空标题的问题。
- `npm test` 扩展为 12 项，通过；模型输出质量和真实语音仍需配置密钥后联调。
